How this report was made: scoring, discovery, safety rules and frameworks

How a path is scored

Score = 100 × exposure × likelihood × impact. Exposure is 1.0 when the entry point faces the internet; 0.6 when someone has to open or click something. Likelihood multiplies the ease of every step, for example 0.9 for a CVE on the CISA KEV list. Impact is how much the crown jewel matters, from 0 to 1. Tiers: critical from 60, high from 40, medium from 20. The exposure index adds up the worst path score to each crown jewel, so it goes down only when a fix actually cuts a path. The fix plan picks the best next fix and re-scores every path after each one, because fixes overlap.
